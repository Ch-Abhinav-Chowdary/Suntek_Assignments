# Ecommerce

This folder contains the week 4 Ecommerce backend project.

## Contents

- `server.js` — main Express server entry point
- `package.json` — project dependencies and scripts
- `package-lock.json` — locked dependency tree
- `APIs/` — API route definitions
- `Models/` — database models
- `test.http` — HTTP request examples for testing endpoints

## Notes

Run `npm install` to install dependencies, then use `npm start` or `node server.js` to launch the server.
