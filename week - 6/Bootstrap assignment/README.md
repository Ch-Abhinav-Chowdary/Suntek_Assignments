# Bootstrap Assignment

## Overview
A responsive landing page project demonstrating HTML structure and CSS styling techniques. The page features a banner section, call-to-action button, and a grid of content cards.

## Project Structure
```
Bootstrap assignment/
├── index.html      # Main HTML structure
├── styles.css      # Custom CSS styling
└── README.md       # This file
```

## Features
- **Hero Banner Section**: Eye-catching banner with heading, descriptive text, and "Learn more" CTA button
- **Card Grid Layout**: Three responsive cards displaying content with:
  - Section headings
  - Lorem ipsum text descriptions
  - "View details" buttons
- **Custom Styling**: Fully styled with custom CSS for layout, colors, and typography

## How to Use
1. Open `index.html` in a web browser
2. Customize the text content and styling in `styles.css` as needed
3. Modify the banner and card content in `index.html`

## Technologies Used
- HTML5
- CSS3

## Notes
- This is a static HTML/CSS project with no backend dependencies
- All styling is contained in the `styles.css` file
- The layout is designed to be responsive across different screen sizes
