# Responsive Layout

## Overview
A responsive layout exercise demonstrating CSS Grid and/or Flexbox techniques. This project showcases how to create flexible, responsive layouts that adapt to different screen sizes.

## Project Structure
```
resposive layout/
├── index.html      # HTML structure with 7 child elements
├── style.css       # CSS styling for responsive behavior
└── README.md       # This file
```

## Features
- **7-Element Grid**: Parent container with 7 numbered child elements
- **Responsive Design**: Layout adapts smoothly across different screen sizes:
  - Mobile screens (small devices)
  - Tablet screens (medium devices)
  - Desktop screens (large devices)
- **CSS Grid/Flexbox**: Demonstrates modern CSS layout techniques

## How to Use
1. Open `index.html` in a web browser
2. Resize your browser window to see the responsive behavior
3. View the `style.css` file to understand the responsive layout techniques used
4. Modify the CSS to experiment with different breakpoints and layouts

## Technologies Used
- HTML5
- CSS3 (Grid/Flexbox)
- Media Queries for responsive design

## Learning Outcomes
This project demonstrates:
- Creating flexible grid layouts
- Using media queries for responsive design
- Understanding CSS Grid or Flexbox properties
- Designing layouts that work across multiple devices
