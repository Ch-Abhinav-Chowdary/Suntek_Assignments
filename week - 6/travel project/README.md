# Travel Project - Libertarians

## Overview
A thematic website dedicated to libertarian philosophy and concepts. The project features a navigation bar, hero section with imagery, and multiple content sections discussing libertarian principles.

## Project Structure
```
travel project/
├── index.html      # Main HTML structure
├── styles.css      # Custom CSS styling
└── README.md       # This file
```

## Features
- **Navigation Bar**: Branded header with "Libertarians" title and decorative symbol
- **Hero Section**: 
  - Main heading and descriptive lead text
  - Featured image (bird.png from SH directory)
- **Content Sections**: Three discussion topics:
  - "But what about the roads?" - Economics and infrastructure discussion
  - "Is taxation theft?" - Tax philosophy perspective
  - "So, what you're Saying is...?" - Summary of libertarian principles
- **Styled Typography**: Custom color scheme with distinct text styling for headers and content
- **Responsive Layout**: Structured to work across different devices

## How to Use
1. Ensure the image path `../SH/bird.png` is correctly set up in your project structure
2. Open `index.html` in a web browser
3. Browse through the content sections
4. Customize the text, styling, and images as needed

## Technologies Used
- HTML5
- CSS3

## File Dependencies
- `../SH/bird.png` - Featured image used in the hero section (ensure this path exists)
